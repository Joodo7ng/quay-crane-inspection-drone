# 폰 미러링 → 실시간 탐지 테스트 순서

**목표: 드론 앱 영상(폰) → 노트북 화면 캡처 → 실시간 균열 탐지 → 대시보드**
소요 30~40분. 오늘 밤에 한 번 돌려보고, 내일은 그대로 반복만 하면 됨.

---

## 0단계. 준비 (인터넷 되는 WiFi에서)

```bash
cd ~/ICT_Drone_Dev
pip install mss streamlit-autorefresh --break-system-packages
```

**맥 권한 2개 — 이거 안 하면 무조건 실패한다**

1. **화면 기록**: 시스템 설정 → 개인정보 보호 및 보안 → **화면 기록** → **터미널** 켜기
2. 켠 뒤 **터미널을 완전히 종료(Cmd+Q)했다가 다시 열기** ← 재시작 안 하면 권한이 안 먹음

✅ **확인**: 시스템 설정 화면 기록 목록에 터미널이 체크돼 있다.

---

## 1단계. 모델·코드 먼저 단독 테스트 (미러링 없이)

미러링부터 하지 말고, **탐지가 되는지부터** 확인한다. 여기서 막히면 미러링을 해도 소용없다.

```bash
cd ~/ICT_Drone_Dev
streamlit run dashboard.py
```

- 사이드바 → 입력 소스 **"사진 업로드"** → 균열 사진 몇 장 올리기 → **▶ 시작**

✅ **확인 3개**
- 사진에 **빨간 마스크**가 칠해져 나온다
- 오른쪽 **종합 안전 상태**에 위험/주의가 뜬다
- 아래 **탐지 기록**에 줄이 쌓인다

⚠️ **주의**
- 첫 실행 때 모델 로딩에 **20~30초** 걸린다. "Running..." 떠도 정상. 기다려라.
- 이메일 물으면 그냥 **엔터**.
- **여기서 마스크가 안 뜨면** → 내일 찍을 대상 사진으로 몇 장 더 시도. 그래도 안 잡히면 모델 문제(팀원 혜민에게 문의)이지 코드 문제가 아니다.

---

## 2단계. 폰 미러링 띄우기

**아이폰**
1. USB로 맥에 연결 (폰에서 "이 컴퓨터를 신뢰" 허용)
2. **QuickTime Player** 실행 → 메뉴 **파일 → 새 동영상 녹화**
3. 녹화 버튼 옆 **∨(화살표)** 클릭 → 카메라 목록에서 **내 아이폰** 선택
4. 폰 화면이 창에 뜬다 (**녹화 버튼은 안 눌러도 됨**)

**안드로이드**
```bash
brew install scrcpy
scrcpy
```
- 폰에서 **개발자 옵션 → USB 디버깅** 켜고 USB 연결, 폰에 뜨는 허용 창 승인

✅ **확인**: 노트북 화면에 폰 화면이 실시간으로 보인다.

⚠️ **주의**: 드론 앱을 켜서 **드론 영상이 폰에 나오는 상태**로 만들어라. (드론 WiFi 접속 필요)

---

## 3단계. 캡처 영역 좌표 구하기 ★ 제일 중요

전체 화면을 캡처하면 **대시보드 자신이 찍혀서 "무한 거울"**이 된다. 반드시 미러링 창만 잡아야 한다.

1. 미러링 창을 화면 **왼쪽**에 놓는다 (대시보드는 오른쪽에 둘 것)
2. `Cmd + Shift + 4` 누른다 (커서가 십자로 바뀜)
3. 미러 창 **왼쪽 위 모서리**에 커서 → 화면에 뜨는 숫자가 **x, y**
4. 거기서 **오른쪽 아래 모서리까지 드래그** → 뜨는 숫자가 **w, h**
5. **`Esc`로 취소** (실제로 캡처할 필요 없음)
6. 메모: `x,y,w,h` (예: `0,100,500,900`)

💡 **모니터가 2개면** 미러 창을 보조 모니터에 두는 게 제일 편하다. 그래도 영역은 지정하는 게 안전.

## 4단계. 실시간 탐지 실행

```bash
cd ~/ICT_Drone_Dev
streamlit run dashboard.py
```

사이드바에서:
1. 입력 소스 → **"화면 캡처(폰 미러링)"**
2. **캡처 영역**에 3단계에서 구한 `x,y,w,h` 입력
3. **▶ 시작**

✅ **확인 4개**
- 가운데 영상에 **폰 화면(드론 영상)만** 보인다 (대시보드가 겹쳐 보이면 영역이 잘못된 것)
- 균열에 **빨간 마스크**가 실시간으로 칠해진다
- 오른쪽 **종합 안전 상태 / FPS / 지연시간**이 계속 갱신된다
- **알림**이 쌓이고, 아래 **탐지 기록**이 늘어난다

⚠️ **주의**
- FPS는 **1~3 정도로 낮게 나온다. 정상이다.** (노트북 CPU 추론이라 그럼. 젯슨 GPU에선 빨라짐)
- 너무 느리면 사이드바 **탐지 주기**를 0.5~1.0초로 올려라
- **중지**를 눌러야 아래 기록에서 `보기` / `조치` 체크를 누를 수 있다 (감시 중엔 읽기 전용)

---

## 5단계. 화면 녹화 테스트

1. `Cmd + Shift + 5` → **선택 부분 기록** 또는 **전체 화면 기록**
2. 미러 창 + 대시보드가 **둘 다 들어오게** 범위 잡기
3. 10초쯤 찍고 재생해서 확인

✅ **확인**: 녹화 영상에서 마스크·등급·알림이 잘 보인다. 글씨가 작으면 브라우저를 `Cmd + +`로 확대.

---

## 문제 해결

| 증상 | 원인 / 해결 |
|---|---|
| 화면 캡처가 검게 나옴 | 화면 기록 권한 없음 → 0단계 다시, **터미널 재시작 필수** |
| 화면 속에 화면이 무한 반복 | 캡처 영역 미지정 → 3단계대로 좌표 넣기 |
| 마스크가 안 뜸 | 모델이 그 표면을 못 잡는 것. 다른 균열로 시도. 코드 문제 아님 |
| `ModuleNotFoundError: mss` | `pip install mss --break-system-packages` |
| 너무 느림 / 버벅임 | 탐지 주기 올리기(0.5~1.0), 미러 창 크기 줄이기 |
| 폰 화면이 안 뜸(아이폰) | 케이블이 충전 전용일 수 있음 → 데이터 케이블로 교체 |
| 드론 영상이 폰에 안 나옴 | 폰이 드론 WiFi에 접속돼 있는지 확인 |

## 폴백 (미러링이 끝내 안 되면)

사이드바 입력 소스만 바꾸면 된다. **결과물은 거의 같다.**

- **"영상 파일"** — 드론 촬영본을 노트북에 옮기고 경로 입력
- **"사진 업로드"** — 드론 사진을 올려서 탐지

미러링에 1시간 이상 매달리지 마라. 폴백으로도 시연은 성립한다.
