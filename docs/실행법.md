# 사진 → 균열 탐지 → 대시보드 (실행법)

**이건 대시보드 가이드의 "2단계: 실제 탐지와 연결"이다.** 대시보드는 한 줄도 안 바꾼다.
`detect_photo.py`가 사진을 보고 균열을 찾아서, 대시보드가 읽는 `detections.csv`에 기록하고
박스 그린 이미지를 `caps/`에 저장한다. 그게 전부다.

---

## 0. 이 폴더 통째로 crane 폴더에 넣기

압축을 풀면 이런 게 들어있다.

```
detect_photo.py     ← 탐지 스크립트
crack_yolo.pt       ← 균열 탐지 모델 (공개 모델, 임시)
sample_photos/      ← 테스트용 균열 사진 2장
실행법.md            ← 이 문서
```

`detect_photo.py`와 `crack_yolo.pt`를 **dashboard.py가 있는 crane 폴더 안에 넣어라.**
(같은 폴더여야 한다. 대시보드와 같은 `detections.csv`를 봐야 하니까.)

---

## 1. 라이브러리 한 번 설치

터미널을 crane 폴더에서 열고:

```
pip3 install ultralytics opencv-python --break-system-packages
```

2~4분 걸린다. 한 번만 하면 된다. (streamlit·pandas는 대시보드 때 이미 깔았다.)

---

## 2. 탐지 실행

**샘플로 먼저 테스트:**

```
python3 detect_photo.py sample_photos --conf 0.2
```

이렇게 나오면 성공이다.

```
  탐지 1 : crack_sample_01.jpg  (conf 0.38) -> caps/crack_sample_01.jpg
  ...
[완료] 사진 2장 중 2장에서 탐지, 총 N건을 detections.csv 에 기록했다.
```

**네 사진으로:** crane 폴더에 `photos` 폴더를 만들어 네 균열 사진을 넣고

```
python3 detect_photo.py photos
```

사진 한 장만 볼 때는:

```
python3 detect_photo.py 사진이름.jpg
```

---

## 3. 대시보드에서 확인

```
streamlit run dashboard.py
```

브라우저 표에 방금 탐지한 균열이 줄로 뜨고, 왼쪽에 박스 그린 사진이 보인다.
**여기까지 오면 이번 목표 끝이다.** (대시보드에 사진 기반 탐지 결과가 뜬다)

---

## 자주 쓰는 옵션

| 옵션 | 뜻 |
|---|---|
| `--conf 0.15` | 문턱값을 낮춰 더 많이 잡는다. 안 잡히면 0.15~0.2로 낮춰봐라. 오탐도 는다 |
| `--model 팀원모델.pt` | 모델 교체. **아래 "모델 교체" 참고** |
| `--reset` | 기존 `detections.csv`를 지우고 처음부터. 시연 직전에 깨끗이 시작할 때 |

---

## 모델 교체 — 이게 중요하다

동봉한 `crack_yolo.pt`는 **인터넷 공개 모델**이다. 파이프라인이 도는 걸 오늘 바로 보라고 넣었다.
그런데 이 모델은 남의 데이터로 학습돼서, **네 크레인 사진에는 잘 안 잡힐 수 있다.**
안 잡혀도 스크립트가 고장난 게 아니다 — 모델이 그 사진을 처음 보는 것뿐이다.

**진짜 탐지 품질은 모델이 결정한다. 두 가지 길이 있다.**

1. **비전 담당 팀원 모델을 받는다.** 그 팀원이 만든 `best.pt`를 받아서
   `python3 detect_photo.py photos --model best.pt` 로 꽂으면 끝이다.
   스크립트는 안 바꾼다. (로드맵에서 "모델은 비전 쪽, 나는 젯슨 위에서 돌린다"가 이거다.)

2. **직접 학습한다.** 공개 crack 데이터셋(Roboflow 등)으로 YOLO를 학습해서 `.pt`만 뽑는다.
   학습은 노트북/코랩에서, 돌리는 건 이 스크립트로.

**부식(corrosion)은 이번 범위 밖이다.** 지금은 균열만. 나중에 부식 모델이 생기면
클래스 이름에 `corros`가 들어가면 이 스크립트가 자동으로 대시보드의 '부식'으로 분류한다.

## 대시보드와 어떻게 붙나 (참고)

`detect_photo.py`는 대시보드가 약속한 컬럼 그대로 `detections.csv`에 한 줄씩 append 한다.

```
timestamp, video_time, type, confidence, bbox_x, bbox_y, image_path, status
```

- `type`은 항상 `crack`(또는 `corrosion`) — 대시보드가 이걸로 균열/부식을 센다
- `image_path`는 `caps/파일명.jpg` — 대시보드 왼쪽에 뜨는 사진
- `status`는 `pending` — 대시보드에서 체크박스 누르면 조치완료로 바뀐다
- `video_time` 칸에는 사진 모드라 **원본 사진 파일명**을 넣어둔다 (어느 사진인지 추적용)

대시보드 코드는 건드리지 않는다. csv만 채우면 화면이 알아서 갱신된다.
