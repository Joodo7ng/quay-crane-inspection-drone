# 학습 모델 비교 연결

2026-09-30 추가 구현임. 기준 지침 v2와 기존 기록은 유지함. 가중치 학습·수정 및 논문 원고 수정은 수행하지 않음.

## 사용

사이드바의 학습 모델에서 기존 C0+R0, 실사진 C1+R1, 합성 비교 C2+R1, 부식 보완 C1+리플레이50% 중 선택함. 사진 업로드에서 ‘같은 사진으로 기존 모델과 비교’를 선택하면 동일 원본을 C0+R0 및 선택 조합으로 각각 처리함. 기록 탭에서 두 결과를 나란히 확인하고 재조회 가능함. 합성 선택의 부식은 R1로 유지되며 리플레이 후보는 R1과 별도 ID임.

기존 OpenCV 처리 방식은 ‘직접 지정 · 기존 대시보드 방식’에 보존함. 등록 모델 선택은 논문 비교 처리로 고정함. 모델 선택에 따라 성능 우위를 주장하지 않음. 부재/부위는 지침 연결 입력이며 모델 특징에 추가하지 않음.

## 가중치 및 검증

`criteria/model_registry.json`에 사용자 지정 모델 ID, Drive 상대경로, 기대 SHA256을 보관함. 파일 내용 SHA256 검증을 먼저 수행하고 finite tensor state_dict와 strict=True 로드를 확인함. 잘못된 파일 또는 누락 시 다른 가중치로 대체하지 않으며 모델별 실패 상태를 저장함.

C0는 기존 저장소 파일을 유지함. R0는 검증된 기존 가중치의 동일 사본을 `weights/comparison/R0.pt`에 보관함. 전달 ZIP의 C1/C2/R1/R_REPLAY50은 같은 폴더에 ID별 이름으로 보관함. 가중치는 Git 추적 제외임. 파일 위치는 MODEL_C1 등 환경변수, ICT_EXPERIMENT_ROOT(Drive 실험 폴더 로컬 사본), 화면의 개별 경로로 지정 가능함. MON_CRACK/MON_CORROSION은 C0/R0 경로 지정에 사용함. 경로를 변경해도 SHA가 맞지 않으면 실행하지 않음.

## 추론 조건과 기록

논문 비교는 Pillow RGB 디코딩, PIL bilinear 512×512, 0~1 변환, ImageNet mean/std 정규화, sigmoid >0.5, 최소 영역 제거 없음으로 고정함. strict state_dict 로드 및 encoder_weights=None을 사용함. 파일 해시, 모델 ID, 입력 크기, 전처리, 임계값, 후처리, 추론 모드, 비교 그룹 ID를 관측과 함께 저장함.

`evaluation_masks_*`는 모델의 원래 512×512 이진 예측이며 논문 코드 비교용임. 화면의 좌표 및 면적비는 이진 예측을 nearest 방식으로 원본 크기에 투영한 마스크 기준임. 화면 면적비와 512 평가 격자의 픽셀 비율은 같다고 가정하지 않음. 저장 NPZ에서 두 격자를 분리함. legacy 방식은 원본 크기로 확대한 확률을 이진화하므로 논문 비교와 구분함.

실행 예시임.

```sh
.venv/bin/python detect_run.py 사진폴더 --model-pair C1 R1 --quality usable
.venv/bin/python -m streamlit run dashboard.py
```

## 검증 범위

자동 시험 64건 통과함. 가중치 SHA 불일치·누락 처리, 설정 고정, 비교 그룹 보존, 서로 다른 원본 저장 경로, 평가용 마스크 저장 및 재조회를 포함함. `validation/model_comparison_tests.xml`에 기록함.

trainval의 SB_EX_011 한 장에서 네 조합(고유 가중치 6개, 모델 실행 8회)의 실제 추론·저장·재조회를 확인함. 평가 코드 engine.tensor로 별도 재계산한 512 예측과 모든 모델의 픽셀 차이가 0임. 결과 및 측정 시간은 `validation/all_models_comparison.json`에 기록함. 기존 실험에서 저장한 동일 모델·동일 입력 예측 파일과의 대조는 자료 미확보로 미검증임. CPU 수치이며 새 Test 정확도, 실시간 비행 성능 또는 구조 안전성 검증이 아님.

웹 브라우저의 C1/R1 선택→C0/R0 동일 사진 비교→새로고침 재조회 결과는 `validation/browser_comparison.json`과 대표 화면으로 별도 기록함.
