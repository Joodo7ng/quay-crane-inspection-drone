# 팀 데이터셋

수빈·은수·혜민의 제출 자료를 압축 해제된 파일로 공유하는 폴더임. 각 담당자별 trainval 120장과 test 30장으로 사진 총 450장, Labelme JSON 총 450개임.

각 데이터 묶음의 images/에는 사진, labelme/에는 라벨을 보관함. 기존 metadata.csv와 README.md는 해당 묶음의 출처·분할·사용 이력 기록임. packages.json은 원본 ZIP의 식별 정보이며 파일 열람을 위해 ZIP을 별도로 내려받을 필요는 없음.

## 품질 검토

이번 추가는 보유 자료의 공유이며 새 학습 승인 또는 독립 평가셋 확정을 의미하지 않음. 기존 검수 완료 이력은 보존하되, 사진과 라벨의 품질을 다시 수작업으로 검토하고 사용·수정 후 사용·보류·사용 제외를 판정할 예정임. 검토 결과와 사유는 별도로 기록하며 원본 파일은 보존함.

같은 촬영 사례와 크롭·합성 원본의 연결 관계, 과거 학습·모델 선택에 사용한 이력을 함께 확인해야 함. 혜민 test는 실제 5장과 합성 25장으로 구성되며 전체 450장을 모두 실제 안벽 크레인 사진으로 표현하지 않음.

이전 README와 metadata의 검수·분할 상태는 작성 당시 기록임. 과거의 검수 대기 문구만으로 이후 완료된 검수를 취소하지 않으며, 이번 품질 재검토와 구분함.
