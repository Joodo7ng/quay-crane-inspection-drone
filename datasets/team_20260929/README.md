# 팀 데이터셋 전달 목록

수빈, 은수, 혜민 각 trainval120장과 Test30장의 목록으로 총450장임. 이 폴더는 사진 및 라벨 ZIP의 버전과 분할 상태를 기록하는 목록이며 실제 이미지/JSON 묶음은 포함하지 않음.

- 수빈: train97 / val23 / test30, 사용자 승인 패키지임.
- 은수: trainval120의 분할 미확정, 검수 기록 확인 대기임. 미확정 표시를 임의 승인하지 않음.
- 혜민: train93 / val27 / test30, 출처 공란 및 합성 결함 원본ID 점검 대기임.
- 혜민 학습용은 실제60/합성60, Test는 실제5/합성25임. 부식 학습 사진은 실제 강구조물임.

packages.json에 원본 ZIP 이름, 크기, SHA256 저장함. download_url=null은 아직 실제 공유 링크를 연결하지 않은 상태임. metadata의 로컬 원문 주소와 검수 기록 경로는 공개 목록에서 제외하며 전체 근거는 원본 ZIP과 로컬 검증기록에 보존함.

학습 및 최종 평가 전에 전체 출처 그룹 독립성 확인 필요함. 폴더 이름이나 수량 충족만으로 최종 학습 승인 완료를 의미하지 않음.
