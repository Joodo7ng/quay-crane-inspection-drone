# 다섯 조건 비교 실험

## 목적과 조건

균열의 실제 자료 파인튜닝 효과 및 합성 자료 추가 효과, 부식의 실제 자료 파인튜닝 효과를 분리하여 비교하는 구성임.

|조건|모델|자료|새 학습|
|---|---|---|---|
|crack_baseline|기존 균열|없음|없음|
|crack_real|균열|실제 Train|1회|
|crack_real_synthetic|균열|같은 실제 Train + 합성 Train|1회|
|corrosion_baseline|재학습한 부식 기본 모델|없음|없음|
|corrosion_real|부식|실제 Train|1회|

같은 기본 가중치에서 독립적으로 시작함. 앞 조건의 파인튜닝 가중치를 다음 조건의 초기값으로 사용하지 않음. 정상 사진도 해당 자료 유형에 맞춰 포함함. 합성 부식 학습 자료는 없는 구성임.

## 공정한 비교 설정

균열 두 조건은 같은 실제 Validation만으로 선택함. 합성 Validation은 이번 비교에서 모델 선택에 사용하지 않음. 공통 학습률, 입력 크기, 증강, seed, 임계값을 적용함.

실제 균열 Train의 크기로 정한 고정 업데이트 횟수를 두 균열 조건에 동일하게 적용함. 복원 추출로 같은 batch 수를 사용하고, 기본20라운드 전체 실행 후 최고 Validation IoU 체크포인트 선택함. 두 조건에서 early stopping으로 계산량이 달라지지 않도록 해당 비교에만 조기 종료를 비활성화함. 일반 단일 모델 학습의 기본 early stopping 설정은 유지함. 라운드별 업데이트 수를 history.json에 저장함. 최고 체크포인트가 선택된 시점은 조건마다 다를 수 있음.

## 실행

먼저 기존 import_metadata.py와 data.py로 검수 기록 및 분할 검사를 통과한 prepared/trainval을 생성해야 함. 원본 제출 ZIP을 experiments5.py에 직접 넣는 방식이 아님. 미검수 표시나 누락 출처를 코드가 임의 승인하지 않음.

```bash
python experiments5.py --data /content/prepared/trainval --crack-weights /content/weights/best_E5_tversky.pt --corrosion-weights /content/weights/best_corrosion_efficientnet-b0.pt --out /content/drive/MyDrive/ICT_통합실험0929/runs/five_conditions_v1
```

같은 출력 폴더 재사용은 차단함. 기본 가중치 두 개, 모든 선택 입력의 크기 및 마스크 확인 후 새 학습3회 실행함. Test는 이 명령에서 열지 않음. five_conditions_validation.json에 기본 모델2개와 파인튜닝3개의 Validation 결과 저장함. 조건별 결과표와 비교 이미지 및 가중치는 각 실행 폴더에 저장함.

## 최종 Test

Validation 검토로 조건과 평가 기준을 확정한 뒤 기존 run.py의 lock/test 기능을 각 학습 결과에 적용하는 단계임. 같은 Test 목록을 모든 해당 모델 조건에 사용하고 실제와 합성을 분리함. run.py가 비교용 기본 모델을 다시 평가하므로 균열 기본 모델 행은 두 결과표에 중복될 수 있어 최종 논문 표에서 동일한 기본 모델 행을 한 번만 표시함.

전체 원본 그룹 검사에는 학습 조건에서 제외된 합성 Validation 자료도 포함하여 수행할 필요가 있음. experiments5.py가 저장하는 all_trainval_provenance.json을 그 근거로 보존함. 공통 Test 독립성이 확인되지 않았으면 최종 평가를 실행하지 않음.

## 현재 상태

세 담당자 자료의 목표 수량은 확보한 상태이며 학습 승인 및 전체 출처 독립성 검증은 별도임. 은수 split=unassigned와 검수 기록, 혜민 출처 및 합성 원본 개별ID 확인이 남아 있음. 소프트웨어 검사 결과를 실제 데이터의 학습 결과로 설명하지 않음. 실제5조건 실험 미실행임.
