# 공통 평가 기준과 논문 기록

통합 실험 실행은 수빈 담당, 지표 계산 점검과 결과표 및 논문 3절과 4절 작성은 은수 담당임. 아래 수치는 실행 전 기본 설정이며 실제 논문에는 결과 폴더의 `config.json`과 최종 데이터 목록을 기준으로 기재 필요함.

## 3. 제안 시스템 및 실험 방법

### 3.1 시스템 구성 및 추가 학습

- 균열과 부식의 이진 U-Net 2개를 각각 유지함. 공통 백본은 EfficientNet-B0임.
- 기존 학습 가중치를 필수로 불러오며 인코더의 가중치와 BatchNorm 이동 통계 고정함.
- 디코더와 분할 헤드만 AdamW로 추가 학습함. 기본 학습률 3e-5, weight decay 1e-4, batch 2, 최대 20 epoch, 조기 종료 patience 5임.
- BCE와 Tversky 손실을 0.5씩 합산함. Tversky는 batch 전체 픽셀 기준임. 기본 alpha는 균열 0.3, 부식 0.5이며 beta는 1-alpha임. 설정 비교는 Validation에서만 가능함.
- 학습 증강은 좌우 반전, 낮은 확률의 상하 반전, 90도 단위 회전, 밝기 변화, 약한 블러임. Validation과 Test에는 증강 미적용함.
- 입력은 512x512, 이미지 bilinear 보간과 마스크 nearest 보간 적용함. ImageNet 평균과 표준편차로 정규화함. 리사이즈 후 결함이 완전히 사라지는 사진은 오류로 중단함.
- 기본 체크포인트 선택 기준은 실제 사진 Validation의 결함 IoU 평균임. 정상 오탐과 Precision, Recall을 함께 검토한 뒤 최종 Test 대상 실행을 확정함. IoU만으로 자동 채택하지 않음.

### 3.2 데이터셋 및 평가 방법

- 팀별 고유 사진 수, 실제/합성 수량, 분할별 수량, 고유 원본 및 촬영 사례 수 기록 필요함.
- 정상은 폴리곤 0개인 검수 완료 사진임. 라벨 누락을 정상으로 취급하지 않음.
- 같은 사진의 크롭, 같은 사례, 같은 합성 결함 원본과 배경은 같은 분할로 묶음.
- 각 모델에는 해당 클래스의 완전한 라벨 검수가 확인된 사진만 사용함. 두 라벨이 있으면 두 모델에 사용 가능하므로 모델별 사용 장수와 전체 고유 사진 수가 다를 수 있음.
- Validation은 학습 설정과 모델 선택용, Test는 확정된 모델의 최종 평가용임. 공식 데이터셋의 Test 명칭보다 실제 사용 이력을 우선함.
- 실제 사진과 합성 사진 결과를 따로 작성함. 정상 합성 대조군은 합성 결과에 포함함.

## 평가 계산

마스크의 1은 해당 결함, 0은 배경임. `ignore` 영역은 학습 손실과 모든 지표의 분모에서 제외함. 예측 확률이 0.5보다 클 때 결함으로 처리하는 기본값임.

|항목|계산 및 해석|
|---|---|
|IoU|TP / (TP+FP+FN)|
|Dice|2TP / (2TP+FP+FN)|
|Recall|TP / (TP+FN)|
|Precision|TP / (TP+FP)|
|결함 사진 평균|해당 결함 정답이 존재하는 사진별 지표의 산술평균|
|정상 오탐 이미지 비율|정상 중 FP가 0픽셀보다 큰 사진 수 / 정상 사진 수|
|정상 오탐 면적 비율|정상 사진별 FP / 유효 픽셀 수를 계산한 후 사진 평균|

기본 정상 오탐 판정은 한 픽셀이라도 예측하면 오탐으로 계산함. 혜민 개별 실험의 50픽셀 초과 기준과 다르므로 이전 결과를 같은 표에 그대로 합치지 않음. 기준 변경이 필요하면 Test 이전에 Validation을 이용해 결정하고 학습 설정부터 다시 기록 필요함.

결함 사진에서 예측이 전혀 없으면 Precision을 0으로 처리함. 해당 클래스 사진이나 정상이 없는 집단은 관련 지표를 해당 없음으로 표시함. 모든 사진의 픽셀을 합한 micro IoU는 JSON 보조 기록이며, 논문 주 표의 결함 사진 평균 IoU와 혼용 금지임.

## 4. 실험 결과 및 고찰

`summary.csv` 및 `결과표.md`에서 균열과 부식, 실제와 합성, 학습 전과 후를 구분하여 표 작성함. 아래 해석 순서 적용 가능함.

1. 결함 IoU 변화와 Recall 변화 확인함.
2. Precision 하락 여부 및 정상 오탐 증가 여부 확인함.
3. 정상 평가 수량과 원본 그룹 수를 함께 제시함.
4. 비교 그림에서 놓친 영역과 잘못 검출한 영역의 대표 사례 제시함.
5. 추가 학습의 효과와 촬영 조건 및 라벨 품질에 따른 한계 작성함.

Test가 완료되기 전 결과 수치를 임의 기입하지 않음. 개별 실험의 Validation 수치, 혜민 LOPO 수치, 통합 모델의 최종 Test 수치는 평가 조건이 달라 별도 구분 필요함. 난수 배열로 수행한 코드 검증 수치는 연구 결과가 아님.

드론 완성, Jetson 실행, 새 모델의 대시보드 연동 및 구조 인식 완료는 이번 학습 코드 작성만으로 입증되지 않음. 실제 수행한 항목만 결과로 서술 필요함.
